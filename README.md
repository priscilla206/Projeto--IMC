# Calculadora IMC Final

Projeto de calculadora de IMC com interface responsiva.

## Tecnologias
- HTML5, CSS3, JavaScript
- LocalStorage para persistência

## Estrutura
- index.html - Frontend
- style.css - Estilos
- script.js - Lógica do IMC
- database/DDL.sql - Estrutura do banco
- database/DML.sql - Dados de exemplo
